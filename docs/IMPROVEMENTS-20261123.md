| 问题 | 修复与证据 |
| --- | --- |
| `--no-extract` 或提取异常后无法恢复 | 刷新补齐缺失 extraction，已有结果不覆盖；批量异常记入 errors 并结束 run |

| 跨轮抓取重复入库 | 与库存一起校验来源 ID、DOI、规范化标题；统一 DOI URL、大小写；保留 fetched/skipped 审计 |
| 公开数据被误判为代码开源 | 启发式要求代码/软件/实现的明确可用声明；不再仅凭 publicly available / proprietary 等词判定 |
| 航空培训或地面车辆混入 | 新抓取要求航空语境与混动/电动/储能/模式切换主题同时命中，去掉 aero 子串与 propulsion 单词造成的宽泛命中 |
| `%`、`_` 搜索成为通配符 | 转义 LIKE 字面量，SQL 仍使用参数绑定 |
| 窗口无结果误报空库 | 使用 meta 库存量区分，提供查看全部时间 |
| 部分刷新失败被当作成功提示 | 展示部分完成及错误；页面明确列表筛选与统计窗口的区别 |
| 结果变少导致分页越界 | 自动回到有效页并重新查询 |
