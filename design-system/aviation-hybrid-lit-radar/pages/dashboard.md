# Dashboard — Geometric Bold override · 2026-11-23

用户指定风格：https://www.stylekit.top/zh/styles/geometric-bold 。本页覆盖原 MASTER 的配色、字体与表面规则。

使用已安装 UI UX Pro Max：设计系统检索 research dashboard / analytics dashboard；风格检索 geometric bold bauhaus。数据库返回的 Portfolio Grid/Enterprise Gateway 转化路径不适合本科研看板，不采用；采用其数据密度、对比度、焦点、响应式及减弱动态效果要求。风格条目中的硬阴影与用户参考冲突，以用户参考的无阴影规则为准。

- 黑白画布、纯蓝主强调、纯红/纯黄几何装饰，赭色用于浅黄徽标文字。
- 首屏圆、方、三角叠放；正文不绝对定位，避免文献与图表遮挡。
- 标题使用本地 Arial / Microsoft YaHei / sans-serif，粗字重。大标题按屏宽 32–68px，正文 16px、行距 1.8；不套用海报 160px 到阅读区域。
- 卡片、按钮、筛选直角；无渐变与阴影；骨架使用静态纯色。
- 1440px 最大宽度；列表 + 320px 图表侧栏，1100px 以下单列，768px 以下图表单列。
- 搜索、筛选、导出、摘要和证据控件保留键盘支持与可见焦点。装饰图形 aria-hidden。
- 保留真实数据与 LLM / 启发式标注。列表按搜索筛选，统计仅按时间窗口，并在页面明示。
